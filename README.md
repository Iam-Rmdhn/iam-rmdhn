# 💫 About Me:
An Information Systems student with a strong interest in web and mobile development. I love turning ideas into interactive and useful digital experiences. I’m currently exploring React, Vue, and Flutter to sharpen my front-end and mobile skills, while also learning how to build scalable back-end systems with Node.js and Express. I enjoy working on side projects where I can experiment with new tools, design clean interfaces, and improve performance. I believe that the best way to learn is by building and I’m always looking for new opportunities to collaborate and grow as a developer.<br><br>Let’s connect, share knowledge, and build something awesome together!🔥
